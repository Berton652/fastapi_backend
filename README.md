# fastapi_backend
A Python backend API designed to facilitate money transfers between Qmoney,Orangemoney,,and Afrimoney in both directions ,including Qmoney-to-Qmoney transfers,Afrimoney-to-Afrimoney transfers,Orangemoney-to-Orangemoney transfers.It also supports currency conversion between US Dollars(USD) and Sierra Leoneans Leones(SLE) in both direction
